# Неассоциативные обертывающие алгебры нильтреугольных алгебр Шевалле

## Сборка

Для сборки диссертации можно использовать команду `latexmk dissertation.tex`.

## Правила именования меток (labels)

В диссертации используется строгая система префиксов для меток:

| Тип объекта  | Префикс      | Пример                       |
|--------------|--------------|------------------------------|
| Теорема      | `th:`        | `\label{th:main}`            |
| Лемма        | `l:`         | `\label{l:key-lemma}`        |
| Предложение  | `p:`         | `\label{p:auxiliary}`        |
| Следствие    | `corollary:` | `\label{corollary:result}`   |
| Определение  | `def:`       | `\label{def:standard}`       |
| Замечание    | `remark:`    | `\label{remark:note}`        |
| Формула      | `eq:`        | `\label{eq:main-equation}`   |
| Рисунок      | `fig:`        | `\label{fig:diagram}`         |
| Таблица      | `tab:`       | `\label{tab:results}`        |
| Секция       | `sec:`       | `\label{sec:introduction}`   |

### Автоматическая проверка

Префиксы лейблов теоремных окружений проверяются автоматически при компиляции:

- При неправильном префиксе выдается ошибка с указанием правильного префикса
- Проверка работает только внутри теоремных окружений (theorem, lemma,
  proposition, corollary, definition, remark)
- Лейблы формул, рисунков, таблиц и секций не проверяются

**Примеры:**

```latex
\begin{lemma}\label{l:mylemma}  % ✓ Правильно
\end{lemma}

\begin{lemma}\label{th:mylemma} % ✗ Ошибка: "wrong prefix 'th:', expected 'l:'"
\end{lemma}

\begin{lemma}
  \begin{equation}\label{eq:formula}\end{equation} % ✓ Правильно (eq: разрешен)
\end{lemma}
```

### Использование cleveref с русскими падежами

Для ссылок на теоремы, леммы и другие теоремные окружения используется пакет
`cleveref` с поддержкой русских падежей:

| Команда            | Падеж                   | Пример использования             |
|--------------------|-------------------------|----------------------------------|
| `\cref{th:1}`      | Именительный            | "теорема 1.1"                    |
| `\Cref{th:1}`      | Именительный            | "Теорема 1.1" (с заглавной)      |
| `\crefRod{th:1}`   | Родительный (чего?)     | "теоремы 1.1"                    |
| `\crefDat{th:1}`   | Дательный (чему?)       | "теореме 1.1"                    |
| `\crefVin{th:1}`   | Винительный (что?)      | "теорему 1.1"                    |
| `\crefTvor{th:1}`  | Творительный (чем?)     | "теоремой 1.1"                   |
| `\crefPred{th:1}`  | Предложный (о чём?)     | "теореме 1.1"                    |

**Примеры:**

```latex
Согласно \crefDat{th:main}, получаем...        % "согласно теореме 1.1"
Доказательство \crefRod{l:key} очевидно.       % "доказательство леммы 2.3"
Применим \crefVin{p:auxiliary} к...            % "применим предложение 1.5"
Воспользуемся \crefTvor{l:important}...        % "воспользуемся леммой 3.2"
В \crefPred{remark:note} отмечено...           % "в замечании 4.1"
```

### Множественные ссылки

Для ссылок на несколько объектов одного типа используйте стандартный `\cref`:

```latex
\cref{l:1,l:2,l:3}    % "леммы 1, 2 и 3"
\Cref{th:1,th:2}      % "Теоремы 1 и 2"
```

**Примечание:** Для множественных ссылок поддерживается только именительный
падеж.
